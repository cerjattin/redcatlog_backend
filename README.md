# Red Mujeres Backend

Backend API para la versión Beta de Red Mujeres.

## Stack

- Node.js
- Express.js
- MySQL
- Prisma ORM
- JWT Authentication
- Zod
- Multer-ready uploads
- Winston Logger
- cPanel compatible

## Scripts

```bash
npm run dev
npm start
npm run prisma:generate
npm run prisma:studio
npm run prisma:seed
npm run lint
npm run format
```
